# Kedatech Test

A simple JavaScript practice project that includes a few utility functions and accompanying tests.

## Overview

This repository contains three small functions implemented in JavaScript:

- `maxSubarraySum` - finds the maximum sum of a contiguous subarray
- `sortDescending` - sorts numbers in descending order
- `sumEvenNumbers` - returns the sum of all even numbers in an array

## Project Structure

- `src/` - implementation files
  - `maxSubarraySum.js`
  - `sortDescending.js`
  - `sumEvenNumbers.js`
- `test/` - test files for each function

## Installation

Install the project dependencies with:

```bash
npm install
```

## Running Tests

Run the test suite with:

```bash
npm test
```

## Notes

This project is a lightweight exercise for practicing JavaScript logic, testing, and repository setup.
